## Learnings
- jac retheme generates global.css with `@import "shadcn/tailwind.css"` which must be removed — jac compiler prepends `@import "tailwindcss"` automatically
- @vitejs/plugin-react must be pinned to ^4.x for Vite 6.x compatibility
- jac runtime caches def:pub reader responses for 60s; use window.location.href for hard reload after mutations
- sv import from ".." path: from components/ to services/ use "..services.X"
- list[any] with `result as list[any]` cast needed for sv import return values
- New sandbox pods may have stale/old file versions — project directory writes don't always sync immediately; use shell heredoc to write directly to /app/ paths when needed
- .jacignore excludes files from jac check but NOT from jac start compilation — must move/rename files to prevent them being compiled
